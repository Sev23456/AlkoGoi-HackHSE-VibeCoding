# Первые деньги

**Игра о решениях с деньгами** для старшеклассников и студентов колледжей (16–22 года).

Игрок держит в руках «смартфон» с банком, чатами и другими приложениями и попадает в жизненные
ситуации: друг просит в долг, «деканат» просит паспорт и код из SMS, перекуп продаёт машину по
«уже подписанному» договору. Нужно выяснить условия, принять решение и посмотреть, что из этого
вышло через неделю, месяц или полгода. Разбор показывает, где была развилка и какая проверка помогла бы.

Персонажи в чатах отвечают сами через нейросеть **GigaChat**: игрок пишет им своими словами.

## Быстрый старт

> ⚠️ Игру нужно запускать через сервер и открывать **по ссылке http://localhost:3000**.
> Если открыть `index.html` двойным щелчком, игра запустится, но персонажи будут отвечать только
> заготовленными фразами, без нейросети.

1. Установите **Node.js 18 или новее**: https://nodejs.org (версия LTS). Проверка: `node -v`.
2. Скачайте проект и перейдите в его папку:
   ```
   git clone <ссылка на репозиторий>
   cd <папка с server.js>
   ```
2. Запустите сервер:
   ```
   node server.js
   ```
   В терминале появится строка `Игра запущена: http://localhost:3000`. Окно терминала не закрывайте.
3. Откройте в браузере **http://localhost:3000**

Проверка связи с нейросетью: **http://localhost:3000/api/check** — должно прийти `"ok": true`.

Остановить сервер: `Ctrl + C` в окне терминала.

## Уровни

| № | Уровень | О чём |
|---|---|---|
| 1 | Первое знакомство | Обучение: найти перевод, оплатить обед другу, найти покупку, создать копилку |
| 2 | Друг просит в долг | Сколько можно одолжить, чтобы хватило на аренду и еду, и что выяснить у друга |
| 3 | Ноутбук для работы | Рассрочка «0%» с платной «защитой покупки», доход по месяцам, подушка безопасности |
| 4 | Деньги общие, представления разные | Поездка с друзьями: кто сколько платит, когда планы поменялись |
| 5 | Всё пошло не по плану | Задержка зарплаты: план платежей, обещанные и настоящие деньги, займ «за 5 минут» |
| 6 | Делегация | «Деканат» просит фото паспорта и код из SMS, потом звонит «служба безопасности» |
| 7 | Подписка через перекупа | Пять предложений подписки: семейный слот, оплата на свой аккаунт, «вечный ключ», аналог |
| 8 | Первая машина | Перекуп с поддельной подписью собственника и честный продавец с запретом из-за штрафов |
| 9 | Тайна следствия | Бабушку несколько недель обрабатывают мошенники «из органов», внук пытается помочь |

Все ситуации основаны на реальных историях.

## Технологии

- **Интерфейс:** HTML, CSS, JavaScript без фреймворков. Приложение имитирует смартфон, набор приложений меняется от уровня к уровню.
- **Сервер:** Node.js только на встроенных модулях, без внешних зависимостей (`npm install` не нужен).
- **Нейросеть:** GigaChat API (модель GigaChat-2-Pro) для персонажей в чатах.
- **Логика исходов** отделена от нейросети и считается детерминированно в `public/sim.js`. Автотесты запускаются при каждой загрузке страницы.

## Настройки `.env`

| Переменная | Что это | По умолчанию |
|---|---|---|
| `GIGACHAT_AUTH_KEY` | Ключ авторизации GigaChat API | — |
| `GIGACHAT_MODEL` | Модель: `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-2-Max` | `GigaChat-2-Pro` |
| `GIGACHAT_SCOPE` | Для физлиц не меняйте | `GIGACHAT_API_PERS` |
| `PORT` | Порт сервера | `3000` |

Файл `.env` содержит ключ — **не добавляйте его в репозиторий** (он указан в `.gitignore`).

## Как править промпты

Промпты лежат в `prompts/levelN.json`. Сервер перечитывает их при каждом сообщении, перезапуск не нужен.

У каждого персонажа:
- `persona` — характер и манера речи;
- `situation` — что произошло, с его точки зрения;
- `facts` — чекпоинты осведомлённости. `need` — слова или числа, без которых чекпоинт не засчитается;
  `ask` — о чём должен спросить игрок. Ключи фактов связаны с игрой, не переименовывайте их;
- `positions` — на что персонаж согласен и на что нет;
- `numbers` — суммы, которые персонаж может называть.

Чтобы не сломать JSON: кавычки внутри текста — только «ёлочки» или `\"`, после последнего элемента
запятая не ставится. Поля, начинающиеся с `_`, — комментарии.

## Что игра проверяет за нейросетью

- Деньги, решения и итоги уровней считает игра. Нейросеть только отвечает и отмечает раскрытые факты.
- Отбрасываются ответы с чужими суммами, ссылками, реальными брендами и словами о том, что персонаж — ИИ.
- Персонаж помнит последние 40 сообщений своего чата и то, что игрок уже узнал.
- Если GigaChat не отвечает, персонаж отвечает заготовленной репликой, игра не ломается.

## Полезное для показа

- Кнопка «↺ Заново» перезапускает текущий уровень (со второго нажатия).
- `http://localhost:3000/?artem=reserve` — зафиксировать вариант Артёма на уровне 2 (`reliable`, `uncertain`, `reserve`).
- «Журнал аналитики» на панели: выбор Артёма и переключатель «Живые персонажи».
