# Первые деньги

Игра о решениях с деньгами. На уровнях 2 и 5 персонажи в чатах отвечают через нейросеть GigaChat: игрок пишет им сам.
Уровни 1 и 4 работают по сценарию (на уровне 4 общий чат читают и отмечают важные сообщения).

## Как запустить

1. Установите Node.js версии 18 или новее: https://nodejs.org (кнопка LTS).
2. Скопируйте файл `.env.example` в `.env` и вставьте в строку `GIGACHAT_AUTH_KEY=` свой ключ авторизации из личного кабинета GigaChat.
3. Скачайте сертификат Минцифры в папку `certs`:
   https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
   (Без него сервер GigaChat может не принять соединение. Официальная страница: https://www.gosuslugi.ru/crt)
4. Откройте терминал в папке игры и выполните:
   ```
   node server.js
   ```
5. Откройте в браузере http://localhost:3000

Проверить связь с GigaChat: http://localhost:3000/api/check — должно прийти `"ok": true`.

## Что где лежит

```
server.js          сервер: раздаёт игру и передаёт сообщения в GigaChat
.env               ключ и настройки (создаётся из .env.example)
certs/             сертификат Минцифры
prompts/
  common.json       общие правила для всех персонажей
  level2.json       Артём (три варианта характера)
  level6.json      «деканат»-мошенница, староста, официальный деканат, мама, поддержка банка, «служба безопасности»
  level5.json       заказчик, хозяйка комнаты, кафе, Артём, мошенники
public/
  index.html       разметка
  style.css        стили
  sim.js           расчёты исходов и автотесты
  app.js           интерфейс и логика уровней
```

## Как править промпты

Промпты — текстовые поля в JSON-файлах `prompts/levelN.json`. Сервер перечитывает их при каждом
сообщении, поэтому перезапускать его после правки не нужно.

У каждого персонажа:
- `persona` — характер и манера речи;
- `situation` — что произошло, с его точки зрения;
- `facts` — чекпоинты. Персонаж раскрывает их, только когда выполнено условие, и при повторном вопросе
  пересказывает тот же смысл другими словами. У чекпоинта есть `need` — слова или числа, без которых он
  не засчитается, даже если нейросеть его отметила. Ключи (`purpose`, `landlord` и т. д.) связаны с игрой:
  не переименовывайте их;
- `positions` — на что персонаж согласен и на что нет;
- `numbers` — суммы, которые персонаж может называть. Ответ с другой суммой сервер отбросит.

## Что игра проверяет за нейросетью

- Ответ должен быть в формате JSON, иначе сервер пробует ещё раз.
- Отбрасываются сообщения с чужими суммами, ссылками, реальными брендами и словами о том, что персонаж — ИИ.
- Деньги, решения и итоги уровней считает сама игра. Нейросеть может только отвечать и отмечать раскрытые факты.
- Персонаж помнит последние 40 сообщений своего чата и то, что игрок уже узнал.
- Если сервер или GigaChat не отвечают, персонаж отвечает заготовленной репликой, а следующее сообщение
  снова уходит в нейросеть. Поле ввода не пропадает.

## Полезное для показа

- `http://localhost:3000/?artem=reserve` — зафиксировать вариант Артёма (`reliable`, `uncertain`, `reserve`).
- «Журнал аналитики» на панели: выбор Артёма и переключатель «Живые персонажи».
- Кнопка «↺ Заново» перезапускает текущий уровень (со второго нажатия).
- Без ключа можно проверить, что всё работает: `npm run test-mode` — персонажи отвечают заглушкой.
- Файл `public/index.html` можно открыть и без сервера: тогда персонажи работают только по сценарию.

## Как не сломать JSON

- Длинный текст можно писать списком строк: `"situation": ["первая строка", "вторая строка"]`. Сервер склеит их через перенос строки.
- Кавычки внутри текста — только «ёлочки» или `\"`. Обычная `"` без слеша ломает файл.
- После последнего элемента списка или объекта запятая не ставится.
- Если файл сломан, в терминале появится `Ошибка в prompts/level2.json: …` с номером позиции, а персонажи ответят по сценарию.
- Поля, которые начинаются с `_` (например, `_info`), — комментарии, сервер их пропускает.
